Interaction Details

Queue pill bar
  • Click a pill → scope narrows to that queue
  • Click active pill again → deselect (back to global)
  • Breach indicator (red badge) when queue has overdue items
  • Count shows total items matching queue's label pattern
  • Sorted by urgency: breached queues first
Tabs (3 permanent)
  • My Work — assigned to me + active status
  • Claimable — PENDING + my groups
  • All — full population (no assignee filter)
  • Inline counts show items per tab in current scope
  • All three compose with the selected queue scope
Filter pills (constrained)
  • Status pills show (count) from current scope × tab
  • Zero-count pills are greyed/disabled — not clickable
  • Priority pills always interactive (queues don't constrain priority)
  • Queue label context shown in a scope bar when active
Summary badges (scoped)
  • Total / Overdue / Breach reflect scope × tab
  • Clicking Overdue/Breach still toggles that filter
  • Claim breach only shown on Claimable tab
