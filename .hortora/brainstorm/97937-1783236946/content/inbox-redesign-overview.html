Key Changes

✓ Queue pill bar
Compact pills replace giant cards. Each shows name + count + breach indicator. Always visible.
✓ Dynamic third tab
Selecting a queue adds "Queue: [name]" tab. My Work and Claimable undisturbed. Deselecting removes the tab.
✓ Constrained filter pills
Status pills for statuses not in the queue are disabled/greyed. Priority pills always active. Filter model receives a queue context.
✓ Scoped counts
Total / Overdue / Breach badges reflect the queue's population, not global counts. Label context shown.

Components Affected

Remove: queue-board (grid+list view), queue-card (giant cards), workbench "Queues" tab
Extend: inbox-filter-bar (disabled pill state), inbox-summary-bar (already supports scoped counts), work-item-inbox (queue pill bar + third tab + filter context)
New: queue-pill-bar component, QueueFilterContext type
Simplify: work-item-workbench (remove LeftPanelView union, remove Queues tab logic)
